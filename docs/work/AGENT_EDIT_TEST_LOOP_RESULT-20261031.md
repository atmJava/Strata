## 重复测试判决

576 次测试里有 178 次与前一次命令签名完全重复，表面比例 `30.903%`，但不能直接算浪费：

| 分类 | 次数 |
|---|---:|
| 两次相同测试之间出现新编辑 | 173 |
| 两次相同测试之间没有新编辑 | 5 |
| 成功结果后立即无编辑重复 | 0 |
| 失败结果后立即无编辑重复 | 0 |

绝大多数相同命令是在修改后重新验证，属于正确的编辑—测试行为。没有编辑的 5 次全部落在
无法可靠判定成功/失败的调用里，也不构成高频用户代价。命令签名还会漏掉参数或工作目录稍变
但语义相同的测试，因此这里采取保守口径。

**判决：**`AGENT-EDIT-TEST-LOOP-TRACE` 不产生“减少重复测试”的 Strata 产品候选。
该方向从队列中剔除，不实现测试去重、测试缓存或自动跳过。
