## 三条写作规矩（延续这份文档体系）

1. **结论进台账、状态进 HANDOVER、细节进工装手册**——同一件事不要在三处各写一半。
2. **每条台账条目**：一句话结论 + 臂数/中位 + 原始日志路径 + 脚本名 + "没测什么"；读代码得到的标 *静态阅读，未测*。
3. **过期的写法**：不要删旧文档，在开头加一行状态（"历史/存档/部分过期"）并指向现行的那份——这样引用它的旧条目仍然成立。
